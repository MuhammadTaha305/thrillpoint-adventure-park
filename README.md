# ThrillPoint Adventure Park

Desktop ticketing and maintenance management system for an adventure park.
Java + JavaFX, no build tool.

## Requirements

JDK 17 or higher, and JavaFX. Either use a JDK that bundles it (Liberica Full,
Zulu FX) or download the OpenJFX SDK separately.

## Build and run

```bash
./run.sh
```
